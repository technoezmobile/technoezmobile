# Profile README package

Public profile: https://github.com/technoezmobile

The active design uses the supplied original banner and studio portrait, actual
portfolio project screenshots, the PHYSIFER project’s own quantum core sequence,
and original channel artwork. Sources are in assets/project-sources and
assets/channel-sources. Portfolio originals were copied, not modified.

The navigation buttons use one bold white label at a 230px display width.
Rainbow animation stays on the edges; labels remain stationary and opaque.
Every panel has a full-color still for reduced-motion preferences.

Run `python scripts/render_profile_photography.py` to rebuild the active design.
The daily contribution workflow uses render_motion_profile.py --contributions-only.
Earlier SVG and illustration assets remain archived in the repository history
and package, but are not used in the active README.

The PHYSIFER website deployment returned 404 during review; its project card
therefore links to its YouTube channel. Portfolio screenshots are existing
project images and do not certify the current availability of each deployment.
